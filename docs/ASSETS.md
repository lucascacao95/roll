# Asset provenance and licensing

## Current app icon — original code-generated artwork

Source: [scripts/GenerateAppIcon.swift](../scripts/GenerateAppIcon.swift). Preview:
[branding/roll-icon.png](branding/roll-icon.png). Generated native slots:
`PhotoImporter/Assets.xcassets/AppIcon.appiconset/icon_*.png`.

Created for Roll on 2026-11-24 by Codex as original Core Graphics geometry, under the maintainer's
request to replace artwork of unresolved provenance. The source defines its own rounded shapes,
cartridge, negative/perforations, colors, gradient and shadows. It reads no image input and does not
trace, crop or transform the previous attachment. No image-generation service, third-party illustration,
SF Symbol, font, manufacturer mark or downloaded asset is part of the artwork.

The maintainer-approved repository MIT license covers this source and its generated PNGs, together with
the code/documentation. The copyright holder is the approved Lucas Cacao Souza. This records the actual
creation process and redistribution terms; it is not a claim of trademark exclusivity or legal clearance
against every other film-cartridge design.

Reproduce from the repository root:

```sh
xcrun swift scripts/GenerateAppIcon.swift
```

Ten native slots from 16 to 1024 px and the README preview are rendered directly, without external
packages or network requests. Generated content contains no personal photography, camera/GPS metadata,
bookmarks, paths or user data. Check dimensions, small-size appearance and final bundle resources after
regeneration. Rasterization/PNG encoding can vary with the OS; the geometry and inputs are versioned.

## Superseded attachment — local history sanitized

The former `docs/branding/roll-provisional-source.png` was a supplied conversation attachment; its
creator, original service/account and redistribution terms could not be verified. Temporary-use approval
did not establish those rights. It has been removed from the current tree, and all ten app slots now
contain the new artwork. No rights in the old image are asserted by the current MIT license.

With explicit authorization, seven exact old PNG blobs were replaced in a fresh isolated clone,
preserving the two development commits' code and metadata. The eleven historical paths remain for old
catalog/README compatibility but now contain original repository-generated artwork. No old image blob is
reachable or present in the sanitized local object database. See [ICON_MIGRATION.md](ICON_MIGRATION.md)
for the commit map, byte-level checks, separate private backup and completed remote-update safeguards.

The separately approved exact-lease push updated remote main to the sanitized history on 2026-11-25.
The first remote CI passed; the repository remains private for final review.
Private legacy backups and ignored old DMGs/bundles must not be published or reused as release assets.
The current MIT grant does not assert rights in those old copies, nor erase possible earlier external downloads.
No destructive cleanup, force push or public visibility change accompanied the local history rewrite.

## Demo illustrations and native captures

Demonstration JPEGs are generated by scripts/demo/DemoCapture.swift using original Core Graphics geometry.
They contain a fixed artificial capture time, no camera serial/GPS, and no external photographs.
The generator and illustrations are covered by MIT. Native captures use production SwiftUI views and
these fixtures; system controls/SF Symbols are rendered by macOS, with no external font or symbol files.
The existing six main/selection/history/settings/progress captures did not display the old app icon.
A new About capture displays the replacement icon. See [capture notes](screenshots/README.md).

## Dependencies and branding

No Swift packages or vendored libraries are used. SwiftUI, Foundation, AppKit, Core Graphics, ImageIO,
CryptoKit, UniformTypeIdentifiers and Darwin are platform APIs, not redistributed package dependencies.
The system font and symbols are not bundled as asset files. Brand colors and the text wordmark are
repository code covered by MIT. License rights are distinct from commercial-name/trademark availability.
